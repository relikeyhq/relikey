- The core runs KeyClerk 0.27.0 (was 0.26.3), built from its signed tag: edge protocol 1.4 on the desk side, backup
  and restore with a drill, signed snapshots, SIEM and SOAR. Approvals now need a passkey sign-in: the realm names
  the passkey sign-in as the level `passkey` and KeyClerk's `approvals.acr` requires it, so the first sign-in's
  temporary password can no longer approve. The reconciler signs the identity broker's high-water mark with its own
  key, which the installer creates.
